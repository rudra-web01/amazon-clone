# Amazon E-Commerce Clone

A responsive Amazon-inspired e-commerce web application built with HTML, CSS, and vanilla JavaScript.

## Features

- Product listing and shopping cart
- Add/remove products and update quantities
- Delivery option selection
- Dynamic order summary and payment summary
- Tax, shipping, subtotal, and order-total calculations
- Checkout and order placement using a REST API
- Orders and tracking pages
- LocalStorage-based cart persistence

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6 modules)
- REST API / Fetch
- LocalStorage
- Day.js

## Running the Project

Open `amazon.html` using a local development server such as VS Code Live Server.

> The checkout page uses the SuperSimpleDev backend API for products and order placement, so an internet connection is required for those features.

## Important

Do not commit personal documents, credentials, API keys, or other private files to the repository.
